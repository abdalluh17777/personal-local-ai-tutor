# تثبيت Personal Tutor على ويندوز

هذا الدليل يأخذك من الصفر حتى تتحدث مع معلمك. لا تحتاج أي خبرة برمجية: التثبيت كله **نقرة مزدوجة واحدة**، وهذه الصفحة تشرح ما يحدث وماذا تفعل إن واجهت مشكلة.

[English](INSTALL.md) · [العودة إلى README](../README.ar.md)

---

## 1. تأكد من مواصفات جهازك

| | المطلوب | كيف تتحقق |
|---|---|---|
| **ويندوز** | ويندوز 10 أو 11 بنظام 64-بت | *الإعدادات ← النظام ← حول ← نوع النظام* |
| **كرت الشاشة** | **NVIDIA** بذاكرة **12 GB** على الأقل (يُنصح بـ 16 GB) | *إدارة المهام ← الأداء ← GPU*: الاسم أعلى اليمين و**ذاكرة GPU المخصصة** |
| **تعريف NVIDIA** | تعريف حديث (2025 أو أحدث) | حدّثه من **NVIDIA App** أو من [nvidia.com/drivers](https://www.nvidia.com/Download/index.aspx) |
| **المساحة** | **25 GB** فارغة (نحو **40 GB** مع الصوت العربي) | *مستكشف الملفات ← هذا الكمبيوتر* |
| **الإنترنت** | للتثبيت الأول فقط (تنزيل 20 إلى 30 GB) | |
| **المتصفح** | Chrome أو Microsoft Edge (Edge موجود في ويندوز) | |

> **لماذا NVIDIA فقط؟** النموذج اللغوي وتحويل الكلام إلى نص والصوتان ونموذج النطق كلها تعمل على كرت الشاشة عبر CUDA، وهذا ما يجعلها سريعة وخاصة. لا يوجد عمداً وضع بطيء على المعالج.

**12 GB أم 16 GB؟** مع 12 إلى 15 GB يعمل كل شيء، لكن لا تثبّت الصوت العربي الاختياري. ومع 16 GB ثبّت كل شيء (المقاس: 11.7 إلى 13.2 GB مستخدمة).

## 2. نزّل المشروع

**الطريقة الأولى، بلا Git (الأسهل):**

1. في [صفحة المشروع على GitHub](https://github.com/abdalluh17777/personal-local-ai-tutor) اضغط الزر الأخضر **Code** ثم **Download ZIP**.
2. اضغط على الملف المضغوط بالزر الأيمن واختر **استخراج الكل…**، واختر قرصاً فيه مساحة كافية، مثل `D:\`.
3. سيصبح لديك مجلد مثل `D:\personal-tutor`. يمكنك تغيير اسمه أو نقله قبل التثبيت.

**الطريقة الثانية، باستخدام Git:**

<div dir="ltr">

```powershell
cd D:\
git clone https://github.com/abdalluh17777/personal-local-ai-tutor.git personal-tutor
```

</div>

> 💡 اختر مساراً قصيراً في قرص فيه مساحة، وتجنّب وضع المجلد داخل OneDrive أو أي مجلد متزامن، حتى لا تُرفع غيغابايتات من النماذج إلى السحابة.

## 3. شغّل المثبّت

افتح المجلد و**انقر نقراً مزدوجاً على `Install Personal Tutor.cmd`**.

إن ظهرت رسالة **"Windows protected your PC"** فاضغط **More info ← Run anyway**. هذه رسالة عادية تظهر مع أي ملف تشغيل منزَّل، والمثبّت لا يكتب إلا داخل مجلد المشروع ولا يحتاج صلاحيات مدير.

ستفتح نافذة تمر بـ 9 خطوات:

| الخطوة | ماذا تفعل | حجم التنزيل |
|---|---|---|
| 1. فحص الجهاز | تتحقق من كرت NVIDIA وذاكرته والتعريف والمساحة، وتسألك عن إضافة الصوت العربي | — |
| 2. uv | مدير حزم بايثون (نسخة محمولة) | 18 MB |
| 3. Ollama | يشغّل النموذج اللغوي على كرت الشاشة (نسخة محمولة: لا خدمة ويندوز ولا أيقونة) | 1.4 GB |
| 4. eSpeak NG | الأصوات اللغوية للصوت الإنجليزي ولتقييم النطق | 13 MB |
| 5. بيئة بايثون | Python 3.12 وFastAPI وfaster-whisper وONNX Runtime GPU ومكتبات CUDA 12 | ~3 GB |
| 6. نماذج الصوت | Kokoro (صوت المعلم) وWhisper large-v3-turbo (كلامك إلى نص) ونموذج النطق، الذي يُبنى من أوزانه الأصلية في 5 إلى 10 دقائق | ~4 GB |
| 7. النموذج اللغوي | Qwen 3.5 9B ويُهيأ باسم `tutor` وكل طبقاته على كرت الشاشة | 6.6 GB |
| 8. الصوت العربي *(اختياري)* | SILMA TTS في بيئة مستقلة لنطق الكلمات العربية في الإجابات | ~11 GB |
| 9. التشغيل وتحميل المقررات | يشغّل المعلم، ويحمّل المقررات الستة وقوائم الكلمات، ويعرض إنشاء اختصار على سطح المكتب | — |

تستغرق العملية عادة **30 إلى 60 دقيقة** حسب سرعة الإنترنت. حين ترى **"Done. Personal Tutor is installed and running."** اضغط أي زر فيفتح التطبيق.

> **انقطع التثبيت؟** شغّل المثبّت مرة أخرى فقط: الخطوات المكتملة تُتخطى، والتنزيلات تُكمل من حيث توقفت.

### خيارات المثبّت (للمتقدمين)

من PowerShell داخل مجلد المشروع:

<div dir="ltr">

```powershell
.\scripts\setup.ps1 -WithArabicVoice   # إضافة الصوت العربي دون سؤال (تضيفه أيضاً لتثبيت موجود)
.\scripts\setup.ps1 -NoArabicVoice     # تخطيه دون سؤال
.\scripts\setup.ps1 -NoShortcut        # بلا اختصار على سطح المكتب
.\scripts\setup.ps1 -Yes               # قبول كل الخيارات الافتراضية (تثبيت دون تدخل)
```

</div>

## 4. التشغيل والاستخدام والإيقاف

| | |
|---|---|
| ▶️ **تشغيل** | انقر نقراً مزدوجاً على **`Start Personal Tutor.cmd`** أو اختصار **Personal Tutor** على سطح المكتب. يفتح التطبيق في نافذة مستقلة، وأول إجابة تأخذ ثواني بينما يُحمَّل النموذج على كرت الشاشة. |
| ⏹️ **إيقاف** | انقر نقراً مزدوجاً على **`Stop Personal Tutor.cmd`**: يوقف عمليات المعلم فقط ويحرر ذاكرة كرت الشاشة كلها. افعل ذلك قبل الألعاب أو أي عمل يحتاج الكرت. |
| 🌐 **أغلقت النافذة؟** | المعلم ما زال يعمل. أعد فتحه من الاختصار، أو افتح <http://127.0.0.1:8765> في المتصفح. |

### أول 5 دقائق

1. اضغط اسمك أسفل يسار الشاشة (أو <kbd>Ctrl</kbd>+<kbd>,</kbd>) واكتب **اسمك ومستواك في الإنجليزية وأهدافك**.
2. اضغط زر المقرر أعلى المحادثة (أو <kbd>Ctrl</kbd>+<kbd>K</kbd>) واختر **PSYC 110 ← Lecture 1**، أو **English Stage 1 ← Lesson 01**.
3. اضغط **أيقونة الموجة** بجانب الميكروفون (أو <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Space</kbd>) و**تحدث فقط**. سماعات الرأس تعطي أفضل تجربة.
4. لاحظ تصحيحات إنجليزيتك تحت رسائلك، ثم افتح صفحة **Pronunciation** وجرّب تمرين **/p/ and /b/**.

الشرح الكامل لكل ميزة في **[دليل الاستخدام](USER_GUIDE.ar.md)**.

## 5. حل المشكلات

| المشكلة | الحل |
|---|---|
| **"No NVIDIA graphics card was found"** | التطبيق يحتاج كرت NVIDIA. في الحاسوب المحمول ذي الكرتين تأكد من تثبيت تعريف NVIDIA. |
| رسالة **"The tutor did not start"** | افتح `logs\start.err.log` ثم `logs\server.err.log` و`logs\ollama-server.err.log` لمعرفة السبب، ثم شغّل `Stop Personal Tutor.cmd` وأعد التشغيل. |
| **"Not enough free GPU memory"** أو بطء النموذج | أغلق الألعاب وبرامج المونتاج وتطبيقات الذكاء الاصطناعي الأخرى، ثم أوقف المعلم وشغّله. راقب *إدارة المهام ← GPU*. ومع 12 GB احذف الصوت العربي بحذف `workers\arabic_tts\.venv`. |
| **فشل تنزيل** | تحقق من الإنترنت وشغّل المثبّت مرة أخرى (يُكمل من حيث توقف). بعض شبكات الشركات تحجب GitHub أو Hugging Face. |
| **المنفذ 8765 أو 11434 مستخدم** | نسخة أخرى من المعلم أو Ollama مثبّت بشكل منفصل يعمل. أغلقه (أو شغّل `Stop Personal Tutor.cmd`) ثم أعد التشغيل. |
| **الميكروفون لا يعمل** | اسمح للنافذة باستخدام الميكروفون (أيقونة القفل في إعدادات الموقع)، وتحقق من *إعدادات ويندوز ← الخصوصية ← الميكروفون*. |
| **الكلمات العربية لا تُنطق** | الصوت العربي اختياري: شغّل `.\scripts\setup.ps1 -WithArabicVoice`، والتفاصيل في `logs\arabic-tts.err.log`. |
| **PowerShell يقول إن تشغيل السكربتات معطّل** | استخدم ملفات `.cmd`، فهي تتجاوز هذا القيد لهذا المشروع فقط. أو شغّل: `powershell -ExecutionPolicy Bypass -File scripts\setup.ps1` |

سجل التثبيت الكامل يُحفظ في `logs\setup.log`.

## 6. التحديث والنسخ الاحتياطي وإلغاء التثبيت

- **التحديث:** نزّل النسخة الجديدة، وانسخ إليها مجلد `data\` (فيه كل تقدمك) ومجلدات المقررات التي أنشأتها بنفسك داخل `materials\`، ثم شغّل المثبّت، فيتخطى كل ما هو موجود.
- **النسخ الاحتياطي:** من *Settings ← Data ← Backup*، أو انسخ مجلد `data\`.
- **إلغاء التثبيت:** شغّل `Stop Personal Tutor.cmd` ثم احذف مجلد المشروع والاختصار. لم يُثبَّت أي شيء خارج المجلد.

## أين تُحفظ الأشياء؟

| المجلد | المحتوى | في Git؟ |
|---|---|---|
| `data\` | قاعدة بياناتك: المحادثات والذكريات والأخطاء والمفردات والتقدم والنسخ الاحتياطية | ❌ خاص بك |
| `materials\` | المواد الدراسية، ونسخ من الملفات التي ترفعها | ✅ المرفقة فقط |
| `models\` | النماذج اللغوية والصوتية ونموذج النطق | ❌ تُنزَّل |
| `tools\` | Ollama وuv وPython وeSpeak NG (نسخ محمولة) | ❌ تُنزَّل |
| `logs\` | سجلات الخادم والمثبّت | ❌ |
